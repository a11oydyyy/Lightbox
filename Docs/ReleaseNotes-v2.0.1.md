# Lightbox 2.0.1

## 体验改进

- 为每个文件夹记住排序方式与升降序，切换目录、标签页或重新打开应用后恢复对应设置。
- 统一大图预览进出时的背景、顶部导航与底部控件淡入淡出，改善过渡衔接。
- 预览与对比期间隐藏顶部导航和侧栏按钮，并禁用对应操作。

## 下载

- **Apple Silicon，macOS 15 或更新版本**：`Lightbox-v2.0.1.zip`。
- **Intel 或 Apple Silicon，macOS 13 或更新版本**：`Lightbox-Intel-x86-v2.0.1.zip`，包含 arm64 与 x86_64 两种架构。
- 两个 ZIP 均附带 SHA-256 校验文件。
- 安装包使用临时代码签名，未经 Apple 公证。
