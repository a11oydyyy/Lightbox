# NAS 大图库浏览优化

基于 Lightbox 2.0.6，提供独立的 `2.0.6-local.2` 试用应用。

## 浏览体验

- 递归浏览最多同时读取 4 个目录，减少 SMB 下大量子目录逐个等待的开销。
- 进入目录即启动递归扫描，不等待顶层文件夹卡片载入；优先深入子目录，让第一批图片尽早出现。
- 扫描过程中分批显示图片；单个大目录也能逐步显示。扫描提示显示已发现的图片数和已访问的条目数。
- 图片尺寸和 Finder 标签在列表出现后载入，并显示独立进度。图片解码失败不妨碍标签读取。
- 在同一个递归目录中输入、修改和清空搜索词，直接筛选已有结果；正在进行的扫描和信息读取会继续，无须从头访问 NAS。
- 手动刷新、目录变化通知、隐藏文件设置变化和目录切换会重新扫描；刷新按钮可用于更新 NAS 上由其他设备修改的内容。
- 尺寸批量更新不再重复排序整个图库。目录切换后，旧任务的结果与进度不会覆盖当前页面。
- 保留隐藏文件选项、自然排序、标签筛选及子文件夹搜索；不进入符号链接和应用包，不按私有目录名称排除图片。

## 本地构建

```sh
./script/build_local.sh
```

产物为 `dist/Lightbox Local.app`，使用独立的应用标识、设置和缓存。脚本不替换已安装的正式版。可用 `LIGHTBOX_BUILD_SDK` 指定 SDK；本机没有脚本优先选择的 macOS 26.5 SDK 时使用当前 Xcode/命令行工具 SDK。

本地构建为 ad-hoc 签名，未经过 Apple 公证。

## 验证方法

2026-10-05 的 SMB 现场测试包含 3,549 张图片、913 个子目录、4,981 个访问项。上一版本串行扫描为 50.15 秒，本版为 17.54 秒，图片数量保持一致。该结果来自同一会话的连续测试，未清空系统/SMB 缓存，不能视为严格冷启动对照。245 项 Swift 测试通过，release 构建、签名和压缩包完整性校验通过；真实应用已验证扫描期间显示图片、修改搜索词、缩略图显示和目录切换。

```sh
swift test
LIGHTBOX_BENCHMARK_FOLDER=/path/to/library swift test --filter nasConcurrentEnumerationBenchmark
```

基准测试只读取目录和文件属性，不解码原图或修改源文件。`LIGHTBOX_BENCHMARK_WORKERS=1` 可用于串行对照。实际耗时受 NAS、网络、系统缓存和目录结构影响；完整枚举完成不表示所有缩略图和图片信息均已载入。

回归测试覆盖扫描期间显示图片、单个大目录的渐进结果、取消与跨目录隔离、完整性、隐藏文件、符号链接、应用包、搜索复用、刷新发现新增图片、解码失败时的标签读取和四种界面语言。

底层文件系统读取仍受 macOS/SMB 超时控制。取消会阻止后续读取和过期结果发布，已进入内核的同步读取需要等待系统返回。
