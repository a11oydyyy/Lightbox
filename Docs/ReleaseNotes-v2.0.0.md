# Lightbox 2.0.0

## 新功能

- 全新侧边栏、居中路径顶栏与独立的新标签页，支持多标签浏览和文件夹导航。
- 新增「包含子文件夹」模式，在同一视图浏览当前文件夹及所有子文件夹中的图片。
- 图片信息展示更完整，包含相机品牌与型号、拍摄参数及可用的文件元数据。
- 新增全局繁体中文，支持英语、简体中文、繁体中文和日语；底部模式按钮随文案长度自适应。

## 体验改进

- 统一明暗配色、选中态与克制的交互动效，更新应用图标。
- 改善鼠标、键盘与无障碍操作；文件夹支持单击打开，搜索和路径编辑支持点击外部关闭。
- 修复图片打开与收回时的卡片错位、顶栏遮挡，以及焦点边框、右键菜单等细节。
- 优化滚动状态更新，减少滚动时对侧栏、顶栏等界面的重复刷新。
- 完善自动检查更新、手动更新提示、GitHub 与问题反馈入口。后台检查不会自动安装更新。

## 下载

- **Apple Silicon，macOS 15 或更新版本**：`Lightbox-v2.0.0.zip`。
- **Intel 或 Apple Silicon，macOS 13 或更新版本**：`Lightbox-Intel-x86-v2.0.0.zip`。兼容包包含两种架构，Apple Silicon 正常启动时使用 ARM 原生架构。
- 两个 ZIP 均附带 SHA-256 校验文件。

## 已知限制

- 本版本使用 ad-hoc 签名，尚未完成 Developer ID 签名及 Apple 公证；首次启动可能被 macOS 安全检查拦截。
- Intel 架构已通过本机 Rosetta 功能与自动化测试，尚未完成 macOS 13 Intel 真机验收；不代表 Intel 真机性能测试结果。
