# Lightbox

[English](README.en.md) · [简体中文](README.md) · [繁體中文](README.zh-Hant.md) · **日本語**

Lightbox は、macOS 向けの軽量な画像ブラウザ・整理ツールです。専用ライブラリに画像を読み込むことなく、既存のフォルダを直接閲覧できます。

よく使う場所をピン留めして、プロジェクト素材、ダウンロード、外付けドライブ、NAS フォルダをすばやく切り替えられます。タブ、大きなプレビュー、撮影情報の表示で、日々の画像閲覧・選別・整理をサポートします。

## 機能

- 専用の新規タブページ、タブ切り替え、フォルダナビゲーション
- メイソンリーレイアウトと、現在のフォルダ／すべてのサブフォルダを含む画像表示
- シングルクリックでのプレビュー、キーボードでの画像切り替え、カメラ・撮影設定・ファイル情報の表示
- よく使うフォルダのピン留めと macOS のカラータグ
- 複数選択、ドラッグ＆ドロップ、コピー、ファイル整理
- ライト／ダークの外観、マウス・キーボード操作、アクセシビリティ対応
- 英語、簡体字中国語、繁体字中国語、日本語に対応
- 更新の自動確認と、ユーザーの確認によるインストール

## ダウンロード

最新の公開版は [Releases](https://github.com/a11oydyyy/Lightbox/releases/latest) からダウンロードできます。

| パッケージ | 動作環境 |
| --- | --- |
| `Lightbox-v*.zip` | Apple Silicon、macOS 15 以降 |
| `Lightbox-Intel-x86-v*.zip` | Intel または Apple Silicon、macOS 13 以降 |

互換パッケージには両方のアーキテクチャが含まれ、Apple Silicon で通常起動すると ARM ネイティブで動作します。各バージョンの署名・公証の状況や既知の制限は、リリースノートをご確認ください。
