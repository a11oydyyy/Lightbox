# Lightbox

[English](README.en.md) · [简体中文](README.md) · **繁體中文** · [日本語](README.ja.md)

Lightbox 是一款輕巧的 macOS 圖片瀏覽與整理工具。直接瀏覽現有資料夾，無須先將圖片匯入獨立素材庫。

釘選常用路徑，在專案素材、下載項目、外接硬碟與 NAS 資料夾之間快速切換。支援分頁瀏覽、大圖預覽及拍攝資訊檢視，適合日常瀏覽、挑選與整理圖片。

## 功能

- 獨立的新增分頁頁面、分頁瀏覽與資料夾導覽
- 瀑布流版面，可瀏覽目前資料夾或包含所有子資料夾的圖片
- 按一下預覽大圖，以鍵盤切換圖片，檢視相機、拍攝參數與檔案資訊
- 釘選常用資料夾，使用 macOS 顏色標籤
- 多選、拖放、拷貝與檔案整理
- 支援淺色與深色外觀、滑鼠、鍵盤及輔助使用操作
- 支援 English、简体中文、繁體中文、日本語
- 自動檢查更新，並由使用者確認安裝

## 下載

前往 [Releases](https://github.com/a11oydyyy/Lightbox/releases/latest) 下載最新公開版本。

| 安裝套件 | 適用裝置 |
| --- | --- |
| `Lightbox-v*.zip` | Apple Silicon，macOS 15 或更新版本 |
| `Lightbox-Intel-x86-v*.zip` | Intel 或 Apple Silicon，macOS 13 或更新版本 |

相容套件包含兩種架構，在 Apple Silicon 上正常啟動時使用 ARM 原生架構。各版本的簽章、公證狀態與已知限制請參閱版本說明。
