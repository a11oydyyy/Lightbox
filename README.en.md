# Lightbox

**English** · [简体中文](README.md) · [繁體中文](README.zh-Hant.md) · [日本語](README.ja.md)

Lightbox is a lightweight image browser and organizer for macOS. Browse your existing folders directly, without importing images into a separate library.

Pin frequently used locations and move quickly between project assets, Downloads, external drives, and NAS folders. Tabs, large previews, and photo metadata make it easy to browse, select, and organize images.

## Features

- An independent new-tab page, tabbed browsing, and folder navigation
- A masonry layout with a choice of the current folder or images from all subfolders
- Single-click previews, keyboard image navigation, and camera, exposure, and file information
- Pinned folders and macOS color tags
- Multiple selection, drag and drop, copying, and file organization
- Light and dark appearances, mouse and keyboard controls, and accessibility support
- English, Simplified Chinese, Traditional Chinese, and Japanese
- Automatic update checks, with installation confirmed by the user
